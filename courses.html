Courses

Below are brief overviews of selected courses taught at Tallinn University of Technology’s IT College.

ICS0020 — Logging and Monitoring

Course code: ICS0020
English title: Logging and Monitoring
ECTS: 6
Semester: Autumn
Language: Estonian/English

This course gives an overview of logging and monitoring approaches for operating systems and applications. Students learn to define approaches for centralized logging and monitoring, work with platform logs (e.g., Linux/Windows), implement log requirements, and use solutions such as rsyslog.
Learning outcomes: understanding log management processes, implementing centralized logging and monitoring, performing correlation of events.

ICS0022 — Secure Programming

Course code: ICS0022
English title: Secure Programming
ECTS: 6
Semester: Autumn
Language: Estonian/English

This course introduces the basics of writing secure code and the major techniques used to improve software security. Students learn principles such as input validation, output encoding, secure memory usage, and avoidance of common vulnerabilities like buffer overflows and injection attacks. Learning outcomes: familiarity with secure programming concepts, ability to apply basic secure programming techniques across common languages.

ICS0027 — Web Application Security

Course code: ICS0027
English title: Web Application Security
ECTS: 6
Semester: Autumn
Language: Estonian/English

This course provides an introduction to the security of web applications. Students examine common attack techniques such as SQL injection, cross-site scripting (XSS), cross-site request forgery (CSRF), session attacks, and authentication vulnerabilities, as well as general defense strategies. Learning outcomes: understanding of common web vulnerabilities and ability to explain and apply defenses against them.
